# 遊戲設計文件（Game Design）

> 狀態：依 2026-10-12 的程式碼盤點與使用者需求填寫。標記「待確認」的項目尚未經使用者確認或實測。

## 1. 遊戲概述

- 遊戲名稱：待確認（專案名 Drone_Project202607）
- 一句話介紹：在城市中駕駛無人機，進行穿圈競速或空中搬運任務。
- 遊戲類型：無人機飛行模擬／競速／任務
- 目標平台：PC（鍵盤、手把）＋ VR（OpenXR，無人機 Prefab 內含 XR Origin）；外接遙控器（`UdpReceiver`）待確認
- 美術風格：低多邊形城市（POLYGON city pack）、風格化天空盒
- 遊戲視角：第一人稱 FPV ／ 第三人稱跟隨（C 鍵切換）
- 預計遊玩時長：每關 1–7 分鐘

## 2. 核心體驗

- 玩家主要想做什麼：精準操控無人機穿梭城市，追求最快時間或完美送貨。
- 玩家需要克服什麼挑戰：建築間的狹窄空間、慣性、載重後的操控變化、時間限制。
- 遊戲希望帶給玩家的感受：擬真但不暈眩的飛行感、成功穿越與送達的成就感。

## 3. 核心遊戲循環

1. 選無人機 → 選模式（競速／搬運）→ 選關卡
2. 倒數 3-2-1 → 飛行（穿圈或取貨送貨）
3. 結算（時間/分數、獎牌、排行）
4. 重新挑戰／下一關／返回選單

## 7. 關卡與進程

- 關卡結構（`LevelCatalog.All`）：
  - 訓練場（SampleScene，競速）
  - 城市賽道（City2，競速）
  - 新城區・住宅區（固定場景 CityResidential，競速／搬運，由種子 1207、4×4 街區、樓高 ≤25m 烘焙）
  - 新城區・市中心（固定場景 CityDowntown，競速／搬運，由種子 4242、6×6 街區、樓高 ≤60m 烘焙）
  - 競速路線沿途有固定障礙：行人天橋、跨街電線、跨街布條、施工塔吊、門架標誌；檢查圈半徑 3.5m（訓練場 3.0m）。（待實測難度）
  - CityProcedural 街景為台灣風格（D-013）：騎樓透天厝/公寓、中文招牌、機車停等區、紅綠燈；街上有汽車（Awbmecreations 車輛素材）與路人（CityPeople 素材）移動，無人機可撞到車輛與行人（會觸發撞擊事件）。（待實測）
- 玩家進度：「下一關」依同模式的關卡順序前進；成績記錄於本機排行榜。
- 勝利條件：
  - 競速：依序通過全部檢查點；時間 ≤ 金牌/銀牌門檻給予對應獎牌，其餘銅牌。
  - 搬運：所有訂單處理完或時間到時，至少送達 1 件即過關。全數完整送達＝金牌、送達過半＝銀牌、其餘＝銅牌。
- 失敗條件：搬運模式時間到且 0 件送達。
- 重試／重生方式：R 回到最後檢查點；結算畫面可重新挑戰。

### 搬運任務規則（DeliveryMissionManager）

1. 訂單依序派發，每張訂單在取貨點（黃色光柱）生成貨物。同一關卡使用固定種子，訂單路線每次相同，排行才公平。
2. 抓起貨物後，送貨點（綠色光柱，多在屋頂）出現；HUD 導航指向目標。
3. 在送貨區內「放下」貨物，貨物靜止 0.6 秒即算送達。放在區外時，導航會改指向貨物，提示撿回。
4. 撞擊速度 > 4 m/s 會損傷貨物（載貨時無人機撞擊傳遞 80%）；耐久歸零＝該訂單失敗並進入下一張。
5. 計分：每張 1000 × 完整度 ＋ (標準時間 − 用時) × 10；全數完美送達另加剩餘秒數 × 5。

## 8. UI 與回饋

- 必要畫面：選無人機 → 模式選擇 → 關卡選擇 → 遊玩 HUD → 結算
- HUD 資訊：人工地平線＋俯仰梯、飛行路徑標記、航向帶、速度（m/s、km/h）、相對高度/AGL/垂直速度、油門條、模擬 4S 電池（% 與電壓）、ARMED/模式/視角、飛行計時、返航方向與距離、目標導航（名稱/距離/高度差）、載貨狀態
- 警告：COLLISION、PULL UP、OBSTACLE、LOW BATTERY、BATTERY CRITICAL（閃爍＋警示音）
- 回饋：倒數彈出、檢查點音效、送達/損毀提示、結算數字滾動、按鈕 DOTween 縮放
